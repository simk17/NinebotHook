请将 Xposed API 82 的 jar 放在此目录，文件名任意（例如 api-82.jar）。

下载方式任选其一：
1. 从 https://github.com/rovo89/XposedBridge/releases 找 api-82.jar（若有）
2. 或从 LSPosed 文档/示例项目中的 libs 复制
3. 或浏览器打开以下地址下载后放入此目录：
   https://archiva.interlocsolutions.com/archiva/repository/internal/de/robv/android/xposed/api/82/api-82.jar

放好后重新执行： .\gradlew.bat assembleDebug
